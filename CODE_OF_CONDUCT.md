# Code of Conduct

OpenRanch is for anyone who wants to look after land, water and animals with
cheap, open tools: ranchers, farmers, hobbyists and programmers alike. Nobody
needs to be an expert to be welcome here.

## Expected

- Be kind and patient, especially with beginners.
- Disagree about the work, not the person.
- Assume good intent, and say so when you're unsure.

## Not accepted

- Harassment, insults or personal attacks.
- Discriminatory jokes or language.
- Publishing someone else's private information.
- Spam or promotion that has nothing to do with the project.

## Enforcement

The maintainers may edit or remove comments, close issues, and block accounts
that break these rules. To report a problem privately, use
https://github.com/thewildfirewatchdog/openranch/security/advisories/new and
start the title with "Conduct:".

This code is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
